Privacy Policy

whatmenwanttosayupload. Last updated 11 October 2026.

Who this applies to

whatmenwanttosayupload is a private publishing tool used only by the owner of the What Men Want To Say YouTube channel to upload that channel's own videos. It has no other users and no sign-up.

YouTube API Services

whatmenwanttosayupload uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What information it accesses

With the channel owner's permission, given once through Google's sign-in, the tool can:

  • upload videos to the What Men Want To Say channel, set their title, description, tags, thumbnail, captions, language and publishing time, add them to the channel's own playlists, and post the channel's own first comment under them;
  • read basic details and public statistics (such as views and likes) of the channel's own videos.

It does not access viewers' personal information, messages, watch history, or any other YouTube account.

How the information is used

Only to publish the channel's videos, organise them into playlists and see how they perform. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How it is stored

The sign-in permission (a token issued by Google) is kept as an encrypted secret in the channel owner's private GitHub repository and on the owner's own computer. Video statistics are kept in that private repository. Nothing is stored anywhere else.

Sharing

No information is sold, shared with, or disclosed to any third party.

Cookies and tracking

The tool has no website users, so it uses no cookies, analytics or tracking. This page sets no cookies.

Removing access

The channel owner can remove the tool's access at any time in their Google Account's third-party access settings. Stored statistics are deleted on request or when the tool is retired.

Changes

If this policy changes, the new version will be posted on this page with a new date.

Contact

Questions about this policy can be sent through the contact details on the What Men Want To Say YouTube channel's About page.
